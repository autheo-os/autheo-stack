03 / A SINGLE LOAD

What would move
through the stack?

A brokered reefer load makes the architecture concrete without pretending a demo generated real-world proof.

  1. 01

    Run the workspace

    Layer 0 hosts the project and its supporting services.

  2. 02

    Ask with authority

    An agent queries MCP tools; a scoped mandate governs what that agent may request in the trust prototype.

  3. 03

    Record custody

    AssetTrack models tender → pickup BOL and seal → transit → receiver-signed POD. Exceptions pause the clean path.

  4. 04

    Verify, then settle

    Future integrations can anchor validated proof and release payment only when authorized conditions hold. The current pilot does neither.

04 / IMPLEMENTATION BOUNDARY

A map of the direction.
Not a claim of completion.

This site illustrates how independently developed Autheo projects can fit together. Today, the agent environment is a local reference simulation, the MCP surface is a configured prototype, and AssetTrack's sample DIDs and reefer handoffs are illustrative. Production DID registration, cross-product integration and automatic on-chain settlement require additional work and verification.
